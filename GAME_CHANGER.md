### API Integration Example

```bash
# Submit project via API
curl -X POST "http://api.bpb26.com/api/projects" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Residential Complex",
    "address": "456 Oak Ave",
    "project_type": "Multi-Family",
    "jurisdiction": "Portland, Oregon"
  }'

# Instant compliance check
curl -X POST "http://api.bpb26.com/api/compliance/check" \
  -d '{"project_id": "abc123"}'

# Response in milliseconds with:
# - Compliance score
# - Detailed violations
# - Recommended actions
# - Applicable regulations
```
